Cuatro servicios, cada uno con un trabajo claro.

| Servicio | Su trabajo |
| --- | --- |
| **Amazon S3** | Sirve la interfaz web |
| **API Gateway** | Expone la API pública |
| **AWS Lambda** | Ejecuta la lógica, sin servidores que administrar |
| **Amazon DynamoDB** | Guarda los lugares y sus señales |
